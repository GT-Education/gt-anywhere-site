## 2. Findings per question

| Q | Finding | Evidence tier | Source(s) |
|---|---|---|---|
| Q1 dual-path pages, comparison blocks, one-question router | Decision time rises with the number of options offered (Hick's Law, Hick 1952 / Hyman 1953); a minimal first choice (two doors) is faster to resolve than a denser one | Documentation | S30, S31 |
| Q1 | Users spend the large majority of page-viewing time in the top 20-40% of a page and stop scrolling once they stop finding a reason to continue ("illusion of completeness"); average time above the fold has fallen from ~80% (2010) to ~57% (2018) as design norms shifted, so a hard 100%-above-fold rule is not itself supported, but early payoff still is | Documentation | S04 |
| Q1 | Comparison/attribute tools work when attributes are presented consistently across every item compared; inconsistent attribute display measurably hurts users' ability to evaluate and choose | Documentation (e-commerce domain, analogic to a school comparison table) | S07 |
| Q1 | "Quiz funnel" vendors claim 3-5x conversion vs. standard landing pages and 40-65% opt-in rates for single-question qualifiers | Opinion — vendor marketing, unrelated verticals (beauty/e-commerce), no disclosed methodology, not independently reproducible | S36 |
| Q1 | None of the quiz-funnel evidence uses a feasibility question ("can you") the way GT's proposed helper does (DD-24); all cited examples elicit a stated preference or attribute (skin type, budget). A feasibility question and a preference question are not interchangeable, and this gap is exactly Astra's DD-24 objection (commuting distance to Georgetown does not mean a family prefers it, since TEFA makes Anywhere free) | Opinion — my synthesis, not a sourced claim | none (reasoned from S36 plus the existing DD-24 register text) |
| Q1 | Higher-ed program finders succeed when they use the vocabulary visitors actually search for (e.g., "majors," "degrees") rather than institutional vocabulary ("academics"), and fail on mobile when heavy | Opinion / case study mix (agency blog case examples) | S34 |
| Q2 above-the-fold and trust signals | Same NN/g scrolling data as Q1: no fixed "fold" line is sacred, but early, decisive content still captures most attention | Documentation | S04 |
| Q2 | School-website vendor guidance converges on: lead with one specific, verifiable proof point instead of mission language; separate current-family and prospective-family paths; make the school's differentiator a nav element, not prose; two-thirds-plus of parents browse on mobile | Opinion (vendor/agency blogs, no disclosed methodology) | S35 |
| Q2 | Third-party validation (accreditation, rankings, alumni/parent survey results) is repeatedly claimed to outweigh first-person claims in parent trust; specific lift percentages (e.g., "42% conversion increase," "83% trust more with badges") have no traceable original study in the sources fetched | Opinion (marketing vendor blogs) | S35, S37 |
| Q2 | WCAG 1.4.1 (Level A): color must never be the only way information, an action, or a distinction is conveyed. This is a conformance requirement, not a preference, wherever WCAG AA is the target (as `1_spec/13`'s X layer already plans) | Documentation (W3C standard) | S33 |
| Q2 | Nielsen's Error Prevention heuristic (#5 of 10, foundational, still current): the best designs prevent the error before it happens, via elimination of the error-prone condition or a confirmation step | Documentation (original, foundational UX research) | S06 |
| Q3 paid-social message match and variant testing at low traffic | Pages with strong ad-to-landing message match reportedly convert up to 2.5x better in Unbounce's own aggregate benchmark data; message-match fixes are treated as one of the fastest, highest-leverage CRO changes across independent CRO literature | Case study leaning opinion (single-vendor aggregate data on the multiplier; the qualitative direction is broader industry consensus) | S01, S02, S03 |
| Q3 | Dynamic query-matched headlines are claimed to lift paid conversion 10-20% | Opinion (vendor claim, not independently verified) | S02 |
| Q3 | Standard A/B-test power analysis: detecting a 10-20% relative lift on a 2-5% baseline conversion rate at 95% confidence typically needs on the order of 1,000-2,000 conversions per variant; detecting only large (30%+) effects needs meaningfully less traffic, but still far more than a trickle. This math is standard statistical practice, converging across three independent practitioner sources | Documentation (standard method, vendor-published) | S24, S25, S26 |
| Q3 | Applying that math to GT's own baseline (32 paid-social sessions in 28 days, per `0_plan/10`, not a new external source): a 3-variant headline test at current paid-social volume would take on the order of years, not weeks, to reach even a rough read, let alone significance | Documentation-derived inference (my arithmetic on documented method + internal baseline) | S24, S25, S26 (applied to `0_plan/10`) |

| Q4 | Instagram's WebView has reproduced, reported defects: broken text rendering, blocked autoplay/inline video, embedded third-party forms failing to render, and inconsistent freezing across identical device models | Case study (bug-tracker and community-support threads reporting real incidents) | (search-sourced: github.com/flutter/flutter#86776; community.klaviyo.com; community.shopify.com threads), S14 |

| Q5 GA4 cross-domain measurement and first-party parameters | GA4 cross-domain measurement appends a `_gl` URL parameter (carrying client ID and session ID) to links between domains explicitly listed in the data stream's "Configure your domains" setting; it is not automatic for an unlisted host | Documentation (official) | S08 |
| Q5 | GA4 explicitly recommends this feature to prevent "self-referrals" between subdomains that have different cookie scopes — directly on point for adding gt.school, georgetown.gt.school, community.gt.school to the linker list alongside the anywhere+apply pair already configured | Documentation (official) | S08 |
| Q5 | The `_gl` parameter can be silently stripped by URL redirects, URL-cleaning logic, or JavaScript-triggered navigation that bypasses normal click/submit handling — all plausible in a Webflow-plus-Vercel-plus-separate-React-app stack | Documentation (official, explicit limitation) | S08 |

This is precisely why cookie-based identity does not reliably survive the anywhere.gt.school -> apply.gt.school hop, and why first-party URL parameters are the documented fallback | Documentation (official: Google Privacy Sandbox + MDN) | S10, S11 |
| Q5 | Google's own ad-click identifiers (gclid, gbraid, wbraid) are themselves first-party URL parameters purpose-built to survive exactly this kind of cross-context handoff; Google's own guidance warns that redirects, URL cleaners, consent tooling and landing-page builders must not strip them | Documentation-adjacent (trade press summarizing Google's own parameter behavior; I did not fetch Google's primary gclid reference page this pass) | S27 |
| Q6 Consent Mode v2 and CMP/GTM | Consent Mode v2 defines four signals: `ad_storage`, `analytics_storage`, `ad_user_data`, `ad_personalization` (the last two added in v2 specifically for EU consent policy) | Documentation (official) | S09 |
| Q6 | Basic mode blocks all Google tags until the user interacts with the consent banner (nothing sent to Google before that, not even consent status). Advanced mode loads tags immediately with default-denied signals and still sends cookieless "pings" for modeled conversions before consent, then unlocks full measurement after consent. These are materially different behaviors, not one setting | Documentation (official) | S09 |
| Q6 | A CMP (or an equivalent custom build) is required to pass consent state to Google; GTM's per-tag "Advanced > Consent Settings" is the mechanism for tags without native consent checks | Documentation (official) | S09 |
| Q6 | Google required Consent Mode v2 (with a Google-certified CMP from Jan 16, 2024) for any Google Ads/Analytics account using audience features on EEA/UK users by March 6, 2024, and began actively enforcing (cutting off personalized ads, remarketing, conversion tracking for non-compliant accounts) on July 21, 2025 | Opinion-adjacent (corroborated across several independent CMP-vendor summaries of Google's own communications; I did not fetch a single canonical Google announcement page for the date) | S32 |
| Q7 UTM governance for a small team | A "naming convention" (a written rule) and "governance" (a system that mechanically enforces the rule before a link can be created, e.g. a builder with required dropdowns) are distinct; only the second reliably prevents drift | Opinion (vendor framing, but a useful and low-risk distinction regardless of source tier) | S23 |

The two are not additive. Previews/staging need either a real access-control wall (to keep crawlers out entirely) or a crawlable `noindex` (so Google can see and honor it) — not both on the same path | S19 |
